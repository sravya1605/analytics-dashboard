# Sales Analytics Dashboard

A responsive, data-driven analytics dashboard built with React and React Query.

## Features
- KPI cards with live data fetching via React Query (stale-while-revalidate caching)
- Line chart: Monthly revenue trend (Recharts)
- Bar chart: Orders vs Returns (Recharts)
- Data table with search, status filter, sortable columns, and pagination
- Dark theme, fully responsive layout

## Tech Stack
React 18 · React Query v5 · Recharts · JavaScript ES6+

## Run locally
```bash
npm install
npm start
```

## Deploy on Vercel
1. Push this repo to GitHub
2. Go to vercel.com → New Project → Import repo
3. Hit Deploy — zero config needed
